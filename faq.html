Frequently Asked Questions

Find answers to common questions about ltth.app

🚀 Erste Schritte

💰 Ist PupCid's Little TikTool Helper kostenlos?

Ja, komplett kostenlos! Das Tool ist 100% kostenlos und Open Source (MIT-Lizenz). Es gibt keine versteckten Kosten, Premium-Tiers oder Feature-Einschränkungen. Alle Funktionen sind für jeden frei verfügbar.

☁️ Was ist der Cloud Launcher?

Der Cloud Launcher ist eine kleine Windows-Anwendung (~7 MB), die LTTH automatisch herunterlädt, installiert und auf dem neuesten Stand hält. Er bietet automatische Updates, Rollback zu vorherigen Versionen und ein integriertes Version-Management. Alle Daten werden in %LOCALAPPDATA%\LTTH\ gespeichert.

⚠️ Warum erscheint eine SmartScreen-Warnung?

Der Launcher ist eine neue Anwendung, die noch nicht code-signiert ist. Das ist normal für Open-Source-Projekte. Klicke „Weitere Informationen" → „Trotzdem ausführen". Die Datei ist sicher und der Quellcode ist auf GitHub einsehbar.

🍎 Gibt es LTTH für macOS oder Linux?

Der Cloud Launcher ist derzeit nur für Windows verfügbar. macOS- und Linux-Support für den Launcher ist in Planung. LTTH selbst läuft auf allen Plattformen, aber die automatische Installation über den Launcher gibt es vorerst nur für Windows.

💻 Welche Betriebssysteme werden unterstützt?

Der Cloud Launcher unterstützt Windows 10 und Windows 11.

Die automatische Installation über den Launcher ist die empfohlene Methode für Windows-Nutzer. Siehe Download-Seite für Details.

📦 Wie installiere ich das Tool?

Empfohlen: Lade den Cloud Launcher herunter und führe ihn aus. Der Launcher installiert LTTH automatisch und hält es aktuell.

Weitere Details findest du auf der Download-Seite.

🔑 Muss ich Login-Daten eingeben?

Nein, keine Login-Daten erforderlich! Du benötigst nur deinen TikTok-Username (ohne @). Keine Passwörter, keine OAuth, keine Account-Verbindung. Das Tool liest nur öffentlich verfügbare LIVE-Stream-Daten.

🚀 Was bedeutet "Beta-Version"? Ist das Tool stabil?

Ja, das Tool ist produktionsreif und voll funktionsfähig! "Beta" bedeutet, dass aktiv neue Features entwickelt werden und wir Feedback sammeln. Alle Hauptfunktionen (TTS, Alerts, Soundboard, Plugins, OBS-Integration) funktionieren zuverlässig. Gelegentliche Bugs können auftreten - melde sie einfach auf GitHub und wir beheben sie schnell!

🔧 Problemlösung

Häufige Lösungen:
✅ Du musst bereits LIVE sein auf TikTok (nicht im Preview)
✅ Username muss korrekt sein (ohne @)
✅ Firewall/Antivirus könnte Verbindung blockieren
✅ Port 3000 muss verfügbar sein
✅ Probiere Auto-Reconnect (wird automatisch versucht)

Mehr Hilfe: Troubleshooting-Guide

🔊 TTS funktioniert nicht - kein Ton?

Checkliste:
✅ TTS-Plugin aktiviert? (Dashboard → Plugins)
✅ System-Lautstärke nicht auf Stumm?
✅ Standard-Audiogerät korrekt eingestellt?
✅ TTS-Volume im Dashboard hochgedreht?
✅ Probiere Test-Button im TTS-Admin-Panel

Wenn nichts hilft: Support kontaktieren

Automatisch: Der Launcher zeigt verfügbare Updates automatisch an und lädt sie auf Wunsch herunter.

🎯 Wie funktioniert das Flow-System?

Flows = Automatisierung ohne Code! Erstelle "Wenn-Dann"-Regeln:
• Trigger: TikTok-Events (Gift, Follow, Chat, etc.)
• Bedingungen: Gift-Value, Username, Text-Match (mit Regex)
• Actions: TTS, Alerts, Sounds, OBS-Szenen, Webhooks

Beispiel: "Wenn Rose-Gift → TTS 'Danke für Rose' + OBS Szene wechseln"

🤖 KI & Daten

🤖 Was ist AnimazingPal?

AnimazingPal ist ein KI-gestütztes Plugin, das VTuber-Avataren ein Gedächtnis und eine Persönlichkeit verleiht. Es erinnert sich an Zuschauer, generiert kontextuelle Antworten über GPT (4o-mini oder 5 Nano) und batchet Events für natürlichen Sprachfluss. Es enthält 5 vordefinierte Streamer-Persönlichkeiten und einen Custom Personality Creator.

🔑 Brauche ich einen OpenAI API-Key?

Ja, für die AnimazingPal Brain Engine und Response Engine wird ein OpenAI API-Key benötigt. GPT-4o-mini und GPT-5 Nano werden unterstützt. Der Key wird sicher und persistent im user_data/-Ordner gespeichert und überlebt Updates.

💾 Werden meine Daten beim Update überschrieben?

Nein. Alle Benutzerdaten, Einstellungen, Plugin-Konfigurationen und API-Keys werden im user_data/- und user_configs/-Ordner gespeichert und überleben Updates. Vor jedem Update wird automatisch ein Backup erstellt.
