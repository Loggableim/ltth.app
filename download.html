Installations-Anleitung

1

Herunterladen

Lade den LTTH Cloud Launcher herunter (~7 MB).

2

Ausführen

Doppelklick auf launcher.exe.

Hinweis: Windows SmartScreen zeigt möglicherweise eine Warnung, da der Launcher noch nicht code-signiert ist. Klicke „Weitere Informationen" → „Trotzdem ausführen". Die Datei ist sicher.

3

Ersteinrichtung

Wähle Installationspfad (Standard: C:\Users\<Dein Name>\AppData\Local\LTTH\versions)

Klicke „Weiter"

4

Automatische Installation

Der Launcher lädt automatisch die neueste Version herunter

Fortschrittsbalken zeigt den Download-Status

Klicke „Starten" wenn die Installation abgeschlossen ist

5

Fertig!

LTTH öffnet sich im Browser. Ab sofort prüft der Launcher bei jedem Start automatisch auf Updates.

Was der Launcher für dich tut

  • ✅ Automatische Installation – Kein manuelles Entpacken, kein Terminal, keine Kommandozeile
  • ✅ Automatische Updates – Prüft bei jedem Start auf neue Versionen, ein Klick zum Updaten
  • ✅ Rollback – Falls nach einem Update etwas nicht funktioniert: Einstellungen → Versionen → vorherige Version wählen
  • ✅ Version-Management – Alle installierten Versionen sichtbar und verwaltbar
  • ✅ Saubere Trennung – App-Daten in %LOCALAPPDATA%\LTTH\, Konfiguration bleibt bei Updates erhalten
  • ✅ Nur ~7 MB – Der Launcher selbst ist winzig, lädt die vollständige App (~25 MB) automatisch nach

System-Anforderungen

  • Betriebssystem: Windows 10 oder neuer
  • Speicher: ~500 MB freier Festplattenspeicher
  • RAM: Mindestens 512 MB, 1 GB empfohlen
  • Internet: Für Download und Updates erforderlich
  • WebView2 Runtime: Wird von Windows 10/11 standardmäßig mitgeliefert. Falls nicht vorhanden: WebView2 herunterladen

Fehlerbehebung

SmartScreen-Warnung:

Der Launcher ist eine neue Anwendung, die noch nicht code-signiert ist. Klicke „Weitere Informationen" → „Trotzdem ausführen".

Weißes Fenster:

Stelle sicher, dass WebView2 Runtime installiert ist. Download

Update schlägt fehl:

  • Internetverbindung prüfen
  • Firewall/Antivirus prüfen
  • Logs prüfen: %LOCALAPPDATA%\LTTH\launcher.log

Launcher startet nicht:

  • Windows 10 oder neuer erforderlich
  • Falls der Launcher abstürzt: Lösche %APPDATA%\ltth-launcher\config.json und starte erneut

🔄 Automatische Updates

Der Launcher prüft beim Start automatisch auf Updates und lädt die neueste Version von LTTH herunter. Deine Konfiguration und Einstellungen bleiben dabei erhalten.
