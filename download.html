Installiere LTTH

Ein direkter Windows-Download. macOS und Linux nutzen weiterhin die One-Line-Installer.

So geht's (für Einsteiger)

  1. Wähle oben dein Betriebssystem oder nutze die automatische Erkennung.
  2. Klicke auf den Download-Button und lade launcher.exe direkt herunter.
  3. Starte launcher.exe und melde dich am Launcher an.

Du musst nichts weiter einstellen. Auf Windows lädst du direkt launcher.exe herunter; Node.js, npm und Native-Module uebernimmt der Launcher beim ersten Start.

Windows — Direktdownload

Lade den signierten Windows Launcher direkt herunter und starte ihn. Er installiert LTTH automatisch und hält alles aktuell.

Windows Launcher herunterladen
⚠ Falls Windows SmartScreen warnt: "Weitere Informationen" → "Trotzdem ausführen". Die launcher.exe ist signiert und sicher. Wenn auf dem System nur Node.js 23.x oder ein anderes ungeeignetes Build vorhanden ist, wechselt der Launcher auf ein unterstütztes LTS-Build, damit native Module ohne Visual Studio-Build-Tools installiert werden können.

macOS — Terminal

Öffne das Terminal, klicke auf "Kopieren" und füge den Befehl anschließend ein.

curl -fsSL https://ltth.app/install/install.sh | bash
💡 Falls Node.js fehlt, wirst du aufgefordert, Homebrew zu installieren (https://brew.sh) — das ist eine einmalige Aktion.

Linux — Bash

Öffne ein Terminal, klicke auf "Kopieren" und füge den Befehl anschließend ein.

curl -fsSL https://ltth.app/install/install.sh | bash
💡 Das Skript nutzt sudo nur, falls Node.js über den Paketmanager installiert werden muss.
Was passiert?

1. Prüfen

Der Windows-Pfad lädt direkt launcher.exe; andere Plattformen folgen ihrem jeweiligen Bootstrap.

2. Laden

Der Windows-Launcher wird direkt von ltth.app geladen und gestartet.

3. Bootstrap

Der Launcher uebernimmt beim ersten Start Node.js 22.14.0, npm install und Native-Module-Rebuilds.

4. Starten

Dashboard öffnet sich unter http://localhost:3000/dashboard.html.

Deinstallation

Der Uninstaller entfernt die LTTH-Installation. Vor dem Loeschen der lokalen Daten und Configs fragt er, ob du sie behalten willst oder alles weg soll.

1. Stoppen

Aktive LTTH-Prozesse werden beendet, damit Dateien sauber geloescht werden koennen.

2. Nachfragen

Du entscheidest im Terminal, ob die lokale LTTH-Konfiguration erhalten bleibt oder mit entfernt wird.

3. Entfernen

Die Installation wird geloescht. Bei Bestätigung werden auch die aktiven Configs und lokalen Daten entfernt.

Windows · PowerShell iex ((iwr -useb https://ltth.app/install/uninstall.ps1).Content.TrimStart([char]0xFEFF))
macOS · Linux · Bash curl -fsSL https://ltth.app/install/uninstall.sh | bash
Alles inkl. Configs loeschen

Bestätige im Uninstaller mit „Ja“ oder setze LTTH_REMOVE_DATA=1 vor dem Befehl. Mit LTTH_KEEP_DATA=1 bleibt die Konfiguration explizit erhalten.

System-Anforderungen

🖥️ Betriebssystem

  • Windows 10 / 11 (1809+)
  • macOS 11 Big Sur oder neuer
  • Linux (Ubuntu 20.04+, Debian 11+, Fedora 36+, Arch)

⚙️ Runtime

  • Node.js 18, 20, 22 oder 24 LTS
  • Git 2.20+ (nur fuer Linux/macOS und Legacy-/Custom-Installationen)
  • ~500 MB freier Festplattenspeicher

🧠 Hardware

  • 1 GB RAM minimum (2 GB empfohlen)
  • Dual-Core CPU
  • Optional: GPU für WebGL/WebGPU-Overlays

🛠️ Häufige Probleme

PowerShell: "Die Skriptausführung ist auf diesem System deaktiviert"

Setze die Execution Policy einmalig: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned und bestätige mit "J".

macOS: "curl: (60) SSL certificate problem"

Aktualisiere curl via Homebrew (brew install curl) oder nutze stattdessen curl -k.

Port 3000 ist belegt

Setze einen anderen Port: LTTH_PORT=8080 curl -fsSL https://ltth.app/install/install.sh | bash

Installation in ein anderes Verzeichnis

LTTH_DIR=/opt/ltth curl -fsSL https://ltth.app/install/install.sh | bash
