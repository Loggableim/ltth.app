Foire Aux Questions

Trouvez des réponses aux questions fréquentes sur ltth.app

🚀 Démarrage

💰 PupCid's Little TikTool Helper est-il gratuit ?

Oui, complètement gratuit ! L'outil est 100% gratuit et Open Source (Licence MIT). Il n'y a pas de coûts cachés, de niveaux premium ou de restrictions de fonctionnalités. Toutes les fonctionnalités sont librement accessibles à tous.

💻 Quels systèmes d'exploitation sont supportés ?

Windows, macOS et Linux sont supportés.

Windows : Windows 10/11 (64-bit) avec installateur setup.exe - installation la plus simple
macOS : macOS 10.15+ - installation manuelle via npm (Installateur natif prévu)
Linux : Ubuntu 20.04+, Debian 11+ - installation manuelle via npm

Toutes les plateformes nécessitent Node.js 18.0.0 ou supérieur.

🔑 Dois-je entrer des identifiants de connexion ?

Non, aucun identifiant requis ! Vous avez seulement besoin de votre nom d'utilisateur TikTok (sans @). Pas de mots de passe, pas d'OAuth, pas de connexion de compte. L'outil lit uniquement les données de stream LIVE publiquement disponibles.

⚙️ Technique

🎥 L'outil fonctionne-t-il avec OBS ?

Oui, intégration OBS complète !
• Overlays Full-HD transparents (1920x1080) comme source navigateur
• OBS WebSocket v5 pour le contrôle des scènes via Cadeaux/Chat
• URLs de source navigateur séparées pour les Objectifs
• Configuration HUD avec Drag & Drop

🔒 Mes données sont-elles uploadées dans le cloud ?

Non, tout reste local ! Toutes les données restent sur votre ordinateur. Pas de connexion cloud, pas de collecte de données, pas de tracking. 100% local et privé.

🔧 Dépannage

❌ La connexion TikTok échoue - que faire ?

Solutions courantes :
✅ Vous devez déjà être en LIVE sur TikTok (pas en Aperçu)
✅ Le nom d'utilisateur doit être correct (sans @)
✅ Le pare-feu/Antivirus peut bloquer la connexion
✅ Le port 3000 doit être disponible
✅ Essayez la reconnexion automatique (tentée automatiquement)

🤖 IA et données

🤖 Qu'est-ce qu'AnimazingPal ?

AnimazingPal est un plugin alimenté par l'IA qui donne mémoire et personnalité aux avatars VTuber. Il se souvient des spectateurs, génère des réponses contextuelles via GPT et regroupe les événements pour un flux de parole naturel.

🔑 Ai-je besoin d'une clé API OpenAI ?

Oui, une clé API OpenAI est requise pour le Brain Engine et le Response Engine d'AnimazingPal. GPT-4o-mini et GPT-5 Nano sont pris en charge. La clé est stockée de manière sécurisée et persistante.

💾 Mes données seront-elles écrasées lors des mises à jour ?

Non. Toutes les données utilisateur, paramètres et clés API sont stockés dans les dossiers user_data/ et user_configs/ et survivent aux mises à jour.
