Plugin-System Features

Modulare Architektur für unbegrenzte Erweiterungen

Hot-Loading

Plugins ohne Server-Neustart laden, aktivieren und deaktivieren. Live-Updates während des Streams.

ZIP-Upload

Plugins einfach via Web-UI als ZIP hochladen. Automatische Installation und Aktivierung.

Plugin Store

Offizielle LTTH-Plugins durchsuchen, installieren und Updates erkennen. Community-Repos sind standardmäßig aus.

Plugin-API

Vollständige API für Express-Routes, Socket.io-Events, TikTok-Events und Datenbank-Zugriff.

Admin-UI

Plugins können eigene Web-Interfaces bereitstellen. Vollständig in Dashboard integriert.

Event-System

Registriere Callbacks für alle TikTok-Events (Gifts, Chat, Follows, etc.). Event-driven Architecture.

Dokumentation

Umfassende Plugin-Dokumentation mit Beispiel-Code, API-Reference und Best Practices.

Erstelle dein eigenes Plugin

Das Plugin-System von ltth.app ist vollständig dokumentiert und einfach zu nutzen. Erstelle custom Funktionalität, teile sie mit der Community oder nutze sie privat für deine speziellen Stream-Anforderungen.
