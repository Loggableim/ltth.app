Système de Plugins

Étendez les fonctionnalités de ltth.app avec des plugins modulaires. Plus de 7 plugins préinstallés et possibilité illimitée de créer les vôtres.

Plugins préinstallés

Tous ces plugins sont inclus et activables dans le gestionnaire de plugins

🎙️

Plugin TTS

Plus de 75 voix TikTok et plus de 30 voix Google Cloud. Mappings de voix utilisateur, Auto-TTS pour les messages du chat, fonction de liste noire et contrôle volume/vitesse personnalisable.

🎵

Plugin Soundboard

Plus de 100 000 sons via la base de données MyInstants. Sons spécifiques aux cadeaux, sons d'événements pour Follow/Subscribe/Share, système de seuil de Likes.

🎥

Multi-Cam Switcher

Contrôlez les scènes OBS via Cadeaux ou commandes Chat. Support OBS WebSocket v5, commandes Chat et système de macros avancé.

🎮

OSC-Bridge (VRChat)

Intégration VRChat via le protocole OSC. Contrôlez votre avatar VRChat avec les événements TikTok. Communication bidirectionnelle avec latence < 50ms.

👥

VDO.Ninja Multi-Guest

Streaming multi-invités avec VDO.Ninja. Gestion de salles, administration des invités et contrôle de mise en page dans une interface unifiée.

🏆

Leaderboard

Top Gifters, plus longues séries et donateurs récents. Mises à jour en temps réel via WebSocket pour vos overlays OBS.

🎨

Emoji Rain

Pluie d'emojis animée sur les Cadeaux. Mappings cadeau-vers-emoji personnalisables, vitesse et densité d'animation configurables.

⚡

OpenShock

Intégration OpenShock pour des expériences de stream interactives. Mappings d'événements, patterns personnalisés et contrôle en temps réel.

🌦️

Weather Control

7 effets météo modernes : Pluie, Neige, Orage, Brouillard, Tonnerre, Rayons de soleil, Glitch Clouds. Rendu Canvas 2D accéléré GPU.

Capacités de l'API Plugin

  • ✅ Routes Express pour des endpoints API personnalisés
  • ✅ Événements Socket.io pour la communication temps réel
  • ✅ Callbacks d'événements TikTok (Cadeaux, Chat, Follow, etc.)
  • ✅ Interfaces Admin UI personnalisées
  • ✅ Hot-loading - rechargez sans redémarrer le serveur
  • ✅ Upload ZIP via le gestionnaire de plugins
