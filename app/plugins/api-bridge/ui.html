Local, read-only reference

API Bridge contract

Inspect these local endpoints before integrating a client. This page never sends an action request.

GET/api/bridge/info

Identify the running LTTH and API Bridge versions.

{ "success": true, "data": { "plugin": "api-bridge" } }

GET/api/bridge/actions

List action IDs and their declared parameters. Reading this endpoint has no side effect.

{ "success": true, "data": [ { "id": "…" } ] }

GET/api/bridge/events?limit=1

Review the most recent event record; a new temporary profile starts with an empty list.

{ "success": true, "data": { "events": [], "total": 0 } }

POST/api/bridge/actions/exec

Execution belongs in a separately tested client. Verify the required body without sending it here.

{ "actionId": "declared-action-id", "context": {} }

Safe integration boundary

Use GET endpoints first. Keep credentials and production action IDs out of screenshots and test profiles; POST execution is intentionally not available on this page.
