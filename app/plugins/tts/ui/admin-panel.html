Engine Settings

Add emotional expression to Speechify voices. Works best with shorter sentences.

Select which engines should be available as fallbacks when the main engine fails. Only enabled engines will be loaded (saves system resources).

Engines with API keys require corresponding keys in the API Keys section. TikTok TTS is free and requires no API key.

Fast mode is optimized for low-end PCs with faster timeouts (5s) and fewer retries (1). Balanced mode is recommended for most users (10s timeout, 2 retries). Quality mode provides maximum reliability for high-end PCs (20s timeout, 3 retries).

When disabled, only the selected engine will be used. If it fails, TTS will not work instead of falling back to another engine.

When enabled, emojis will be removed from messages before they are spoken, preventing the TTS engine from reading emoji names aloud.
