Multi-Language Output:
1. Wähle Default-Sprache (was gesprochen wird)
2. Füge Zielsprachen hinzu (je eine Zeile im Output)
3. Wähle Übersetzungs-Modell (wird automatisch geladen wenn API-Key vorhanden)
4. Starte Capture — jede Zeile zeigt eine Sprache

Übersetzung via Ollama Cloud — muss in den Admin-Settings aktiviert sein.
