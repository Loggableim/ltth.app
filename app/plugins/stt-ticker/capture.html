🎤 STT Ticker - Audio Capture

⏹️ Gestoppt — Mikrofon auswählen und Capture starten
So funktioniert's:
1. Klicke auf 🎤 Capture starten
2. Browser fragt nach Mikrofon-Erlaubnis
3. Wähle dein Mikrofon aus
4. Audio wird an den STT Ticker Server gesendet
5. Transkripte erscheinen im OBS-Overlay
6. Dieses Fenster kann minimiert im Hintergrund laufen
