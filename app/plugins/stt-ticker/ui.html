🎤 Audio-Capture

Das Audio-Capture läuft in einem eigenen Browser-Tab (nicht im iframe). So funktioniert der Mikrofon-Zugriff zuverlässig in allen Browsern.

🎤 Capture-Tab öffnen

Workflow:

  1. Klicke auf "🎤 Capture-Tab öffnen" — neuer Tab geht auf
  2. Im neuen Tab: "▶ Capture starten" klicken
  3. Browser fragt nach Mikrofon-Erlaubnis → erlauben
  4. Audio wird an Fish.audio ASR gesendet
  5. Transkripte erscheinen automatisch im OBS-Overlay
  6. Capture-Tab kann minimiert im Hintergrund laufen
