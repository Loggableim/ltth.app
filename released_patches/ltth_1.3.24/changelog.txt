LTTH Version 1.3.24 Release Notes

Version 1.3.24 uses a Windows ZIP bootstrap: PowerShell downloads the app bundle ZIP plus launcher.exe, then launcher.exe handles Node.js 22.14.0, npm install, and native-module rebuilds on first start.

- IMPROVED: Launcher now auto-pulls Git-backed updates before starting the server
- IMPROVED: Auto-update runs before dependency validation so updated package metadata stays in sync
- IMPROVED: Version metadata bumped to 1.3.24 so the launcher recognizes the new release
- FIXED: Windows one-line installer now downloads the app bundle ZIP on first install; Node.js, npm install, and native-module rebuilds happen in launcher.exe
