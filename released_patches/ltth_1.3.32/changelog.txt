LTTH Version 1.3.32 Release Notes

Version 1.3.32 adds a persistent interactive turn queue for concurrent Connect Four and Chess matches, rotating OBS boards, host controls, and timed viewer turns.

- NEW: Connect Four and Chess share one persistent FIFO queue for concurrent viewer matches
- NEW: The unified OBS overlay rotates all active boards and labels every match as host vs. player
- NEW: Viewers play through chat while the streamer controls host turns from the Game Engine dashboard
- FIXED: The viewer clock runs only on player turns; a timeout causes an automatic player loss
- FIXED: Queue recovery, event deduplication, and host-control races are hardened
- IMPROVED: Public release metadata and download surfaces bumped to 1.3.32
