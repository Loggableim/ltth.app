Cloud Launcher

Le LTTH Cloud Launcher est la méthode d'installation recommandée pour Windows.

Fonctionnalités

  • Téléchargement et installation automatiques : Télécharge automatiquement la dernière version
  • Mises à jour automatiques : Vérifie version.json à chaque démarrage
  • Rollback : Retour aux versions précédentes via Paramètres → Versions
  • Gestion des versions intégrée : Toutes les versions visibles et gérables
  • Séparation propre : Données dans %LOCALAPPDATA%\LTTH\, config préservée

Détails techniques

  • Téléchargement : https://ltth.app/downloads/launcher.exe (~7 Mo)
  • Plateforme : Windows 10+
  • Installation : %LOCALAPPDATA%\LTTH\versions\<version>\
  • Configuration : %APPDATA%\ltth-launcher\config.json
  • Logs : %LOCALAPPDATA%\LTTH\launcher.log
  • Vérification version : https://raw.githubusercontent.com/Loggableim/ltth.app/main/version.json
  • Téléchargement app (interne) : https://ltth.app/app/ltth_latest.zip
  • Prérequis : WebView2 Runtime (inclus avec Windows 10/11)

Rollback

Pour revenir à une version précédente :

  1. Ouvrez les Paramètres dans le Launcher
  2. Allez dans "Versions"
  3. Sélectionnez la version précédente souhaitée
  4. Cliquez sur "Rollback"

Le launcher bascule immédiatement vers la version sélectionnée sans perdre votre configuration.

Première connexion

1. Démarrer l'application

Après l'installation avec le Cloud Launcher, l'application démarre automatiquement et le tableau de bord s'ouvre dans votre navigateur sur http://localhost:3000.

2. Entrer votre nom d'utilisateur TikTok

Entrez votre nom d'utilisateur TikTok sans le @ dans le champ de connexion. Assurez-vous d'être déjà en LIVE sur TikTok avant de vous connecter.

3. Cliquez sur Connecter

Cliquez sur le bouton "Connecter" et attendez que la connexion s'établisse. Vous verrez les événements en temps réel s'afficher dans le tableau de bord.

Configuration OBS

Ajouter l'overlay comme source navigateur

  1. Ouvrez OBS Studio
  2. Cliquez sur le + dans "Sources"
  3. Sélectionnez "Source navigateur"
  4. Entrez l'URL de l'overlay : http://localhost:3000/overlay
  5. Définissez la résolution sur 1920x1080
  6. Cliquez sur OK

💡 Conseil : L'overlay est transparent, vous pouvez donc le superposer sur votre contenu vidéo sans masquer quoi que ce soit.

Configuration Text-to-Speech

Activer le TTS

Dans le tableau de bord, allez dans "Plugins" et activez le plugin TTS. Vous pouvez ensuite configurer les voix, le volume et la vitesse dans le panneau d'administration TTS.

Voix disponibles

  • Plus de 75 voix TikTok - Allemand, Anglais, Français, Espagnol et plus
  • Plus de 30 voix Google Cloud - Qualité premium (optionnel)
