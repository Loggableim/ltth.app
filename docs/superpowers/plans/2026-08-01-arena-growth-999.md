# Arena Growth 999 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make player consumes yield full direct growth and raise the Arena ceiling to mass 999 while preserving calm ambient food.

**Architecture:** `ArenaGame.DEFAULT_CONFIG` owns the new mass/life caps and direct absorb ratios.  The runtime game normalizer and Game Engine admin normalizer recognise only the former shipped defaults and lift them to the new profile.  Collision code remains the single reward path, so no new economy or food emitter is introduced.

**Tech Stack:** Node.js CommonJS, Jest, ESLint, bundled Windows Node runtime.

## Global Constraints

- Work only in `codex/arena-growth-999`; do not alter the dirty `main` checkout or unrelated worktrees.
- Exact new defaults are `maxMass: 999`, `maxLives: 320000`, `playerAbsorbMassRatio: 1`, and `playerAbsorbLifeStealRatio: 1`.
- Migrate direct absorb values only for the prior shipped `maxMass: 666`, `playerAbsorbMassRatio: 0.82`, and `playerAbsorbLifeStealRatio: 0.84` profile.  Migrate `maxLives: 88000` only when that same complete former profile is present; preserve partial and custom values.
- Preserve calm ambient food exactly: `maxFood 72`, `maxFoodRender 66`, `foodSpawnIntervalMs 2400`, `foodSpawnBatchSize 1`, `foodDespawnMs 150000`.
- Do not reset an Arena match, start the stopped app, reload a plugin, or alter unrelated gameplay.
