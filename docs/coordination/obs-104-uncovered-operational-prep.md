Status: read-only product-source preparation; no app/server, plugin, provider, hardware, audio, WebGPU, or OBS process was started. This adds prep detail and does not alter the 104-case denominator.

## Scope and method

- The current acceptance matrix has 104 cases: 26 families × `de/en/es/fr`. The central nine are `advanced-timer`, `stt-ticker`, `goals`, `spotlight`, `quiz-show`, `toptier`, `interactive-story`, `viewerxp` (matrix ID `milestone-leaderboard`), and `webgpu-weather-control`; apply that alias before differencing. They account for 36 cases; the 17 remaining matrix families account for 68 cases. The denominator remains 104.
- “Uncovered” below means outside those nine centrally curated fixture families. It does not mean there is no supplemental CPU or synthetic-browser evidence elsewhere in the workspace. In particular, the standard `weather-control` and `music-bot` families have separate local evidence; neither is folded into the central nine by this table.
- The 17 groups below are taken from `docs/coordination/obs-104-acceptance-matrix.json`. Matrix URLs are plans, not proof of current routability. Current route, handler, and served HTML were cross-checked against `docs/coordination/obs-route-resolution.md`, `app/modules/public-overlay-registry.js`, and the registered plugin handlers. Direct plugin static files are served by the global `/plugins` middleware only after plugin loading; this does not make every such file an approved public overlay entrypoint.
- “Registry” refers to `isRegisteredEntrypoint()` in `app/modules/public-overlay-registry.js`, the allowlist used by isolated public-overlay fixtures. A product route may serve a file while still being absent from this isolated-entrypoint contract.
- Every row represents four locale cases. Locale support and visual acceptance are separate: for example, Schnorrbecher currently displays German copy regardless of `?lang`, and the Chatango embed content is provider-owned.

## Route and source findings

- Current registry check confirms 8 of these 17 matrix candidate paths are registered as public entrypoints. Seven other families have a canonical registered route that differs from the matrix direct-file URL: Coinbattle, Fireworks, Game Engine, OpenShock, Talking Heads, Weather Control, and WebGPU Emoji Rain. Minecraft Connect has a product static file but no registered public-overlay entrypoint; Chatango has no dedicated overlay entrypoint. A file existing does not establish that its path is admitted by the isolated fixture registry.
- Canonical product route claims above were confirmed against the source route resolver and plugin route declarations, not by starting the product server. Generic `/plugins` static fallback makes some matrix file URLs technically servable, but those files are not all in the fixture entrypoint allowlist.
- Every referenced original page file in the matrix exists in the current checkout. The notable gap is semantic/contractual rather than a missing HTML file: Chatango lacks a dedicated overlay route; Minecraft Connect’s static file is not in the public-overlay entrypoint registry. External or stateful dependencies are listed per row.
- Product plugin routes are registered during plugin load (`app/server.js` loads plugins before mounting generic plugin static files). Source registration is not proof that a plugin is enabled in any particular profile or that an endpoint currently responds.
