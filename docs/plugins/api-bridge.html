Voraussetzungen

LTTH Dashboard und Zugriff auf die lokale LTTH-URL. Dieser konkrete API Bridge-Ablauf behandelt lokale Aktionen, Ereignisse und die API-Bridge.

Sicherheitsgrenzen

Keine echten API-Schlüssel oder Konten eingeben; Platzhalter bleiben Platzhalter. Dieser konkrete API Bridge-Ablauf behandelt lokale Aktionen, Ereignisse und die API-Bridge.

Zweck und Zielgruppe

API Bridge richtet lokale Aktionen, Ereignisse und die API-Bridge ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Streamer:innen, die lokale Aktionen, Ereignisse und die API-Bridge zuerst ohne LIVE-Auswirkung einrichten möchten.

Aktivierung und Navigation

Öffne im Plugin Manager „API Bridge“, aktiviere es bei Bedarf und rufe dann die lokale Konfiguration auf.

/api/bridge/info

Fehlerbehebung

Wenn lokale Aktionen, Ereignisse und die API-Bridge nicht sichtbar ist, prüfe zuerst den aktiven Plugin-Status, die lokale Route und gespeicherte Testwerte.

Prüfschritte Lokale Guide-Route: /api/bridge/info. Im Plugin-Code deklarierte Schnittstelle: GET /api/bridge/actions.

Lösung Öffne /api/bridge/info, prüfe den im Symptom genannten Zustand und wiederhole anschließend den lokalen Test. Lokale Guide-Route: /api/bridge/info. Im Plugin-Code deklarierte Schnittstelle: GET /api/bridge/actions.
