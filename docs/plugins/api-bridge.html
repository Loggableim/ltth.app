API Bridge

Prueft den lokalen GET-Vertrag der Bridge, ohne eine Aktion auszufuehren.

Status
Funktionsfähige Beta
Version
1.0.0

Dein erstes Ergebnis

Info, Aktionen und Ereignisendpunkt sind als lesbare Referenz sichtbar.

Inhalt

  1. 1. die lokale Read-only-Einordnung pruefen
  2. 2. GET /api/bridge/info pruefen
  3. 3. GET /api/bridge/actions pruefen
  4. 4. GET /api/bridge/events?limit=1 pruefen
  5. 5. die POST-Sicherheitsgrenze pruefen

Voraussetzungen

Aktives Plugin und ein temporaeres lokales Testprofil.

Sicherheitsgrenzen

Nur Lesen und lokale Vorschau; keine produktiven Daten, Zugangsdaten, Exporte oder API-Aktionen ausloesen.

    die lokale Read-only-Einordnung pruefen

    Daran erkennst du den Erfolg: die lokale Read-only-Einordnung ist sichtbar.
