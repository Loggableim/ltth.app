Pup Cid's Little Quiz Show Plugin

Gibt eine lokale Frage ein, startet das Quiz und beendet es wieder ohne Chat.

Status
Entwicklungs-Beta
Version
1.1.0

Dein erstes Ergebnis

Die Frage laesst sich im lokalen Quiz-Dashboard steuern.

Inhalt

  1. 1. Pruefe das Quiz-Dashboard
  2. 2. Pruefe die Testfrage
  3. 3. Pruefe den sichtbaren Quiz-Arbeitsbereich
  4. 4. Pruefe den Start der lokalen Quizfrage
  5. 5. Pruefe das Beenden der lokalen Quizfrage

Voraussetzungen

LTTH-Dashboard mit einem temporaeren lokalen Testprofil.

Sicherheitsgrenzen

Nur lokale Vorschau, Simulation oder Testwerte verwenden; keine LIVE-Verbindung aktivieren.

Schritt für Schritt

  1. 1

    Pruefe das Quiz-Dashboard

    Pruefe das lokale Dashboard als Ausgangspunkt; keine Frage wird dadurch gestartet.

    Daran erkennst du den Erfolg: das Quiz-Dashboard ist am konkreten Bedienelement sichtbar.

  2. 2

    Pruefe die Testfrage

    Sichtpruefung des Quiz-Fragefelds: Kein Fragetext wird in diesem Workflow eingegeben.

    Daran erkennst du den Erfolg: die Testfrage ist am konkreten Bedienelement sichtbar.

  3. 3

    Pruefe den sichtbaren Quiz-Arbeitsbereich

    Pruefe den sichtbaren Quiz-Arbeitsbereich, in dem die Antwortzeit vor einem lokalen Test angezeigt wird.

    Daran erkennst du den Erfolg: den sichtbaren Quiz-Arbeitsbereich ist am konkreten Bedienelement sichtbar.

  4. 4

    Pruefe den Start der lokalen Quizfrage

    Starte die lokale Testfrage nur im Testprofil und ohne Chat-Teilnehmer.

    Daran erkennst du den Erfolg: den Start der lokalen Quizfrage ist am konkreten Bedienelement sichtbar.

  5. 5

    Pruefe das Beenden der lokalen Quizfrage

    Stoppe genau die lokale Testfrage, damit kein Quizfenster offen bleibt.

    Daran erkennst du den Erfolg: das Beenden der lokalen Quizfrage ist am konkreten Bedienelement sichtbar.

Fehlerbehebung

Pruefe, ob das Plugin im Testprofil aktiviert ist, bevor du die Seite neu laedst.
