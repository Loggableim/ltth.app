Pup Cid's Little Quiz Show Plugin

Mit Pup Cid's Little Quiz Show Plugin richtest du eine interaktive Zuschauer-Erfahrung ein. Diese Anleitung führt sicher von Aktivierung bis zum lokalen Test.

Voraussetzungen und Sicherheit

Zugriff: development-beta. Nutze für diese Anleitung ein Testprofil; externe Geräte, Dienste und LIVE-Ausgaben bleiben deaktiviert.

Schritt für Schritt

  1. 1

    Plugin aktivieren

    Öffne den Plugin Manager, suche Pup Cid's Little Quiz Show Plugin und aktiviere das Plugin. Prüfe, dass der Status auf Aktiv steht.

    Erwartetes Ergebnis Der Plugin-Status ist aktiv und der Einstieg ist erreichbar.

  2. 2

    Arbeitsbereich öffnen

    Öffne anschließend den eigenen Arbeitsbereich von Pup Cid's Little Quiz Show Plugin. Lies die sichtbaren Hinweise, bevor du Werte speicherst.

    Erwartetes Ergebnis Die Konfiguration wird ohne Ladefehler angezeigt.

  3. 3

    Sicher konfigurieren

    Lege zuerst nur die kleinste sinnvolle Konfiguration an. Verwende Testwerte und keine echten Zugangsdaten oder Produktionsziele.

    Erwartetes Ergebnis Die Änderung ist gespeichert und jederzeit nachvollziehbar.

  4. 4

    Kontrolliert testen

    Führe den eingebauten Test oder eine lokale Vorschau aus. Prüfe das erwartete Ergebnis, bevor du den Ablauf im LIVE-Stream verwendest.

    Erwartetes Ergebnis Die Vorschau bzw. der Test zeigt das erwartete Ergebnis.

Troubleshooting

Wenn eine Oberfläche nicht lädt, aktiviere das Plugin erneut, aktualisiere den Browser und prüfe den Plugin-Status im Dashboard.
