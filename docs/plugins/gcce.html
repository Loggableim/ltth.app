der Befehl wird validiert, ohne eine LIVE-Chatnachricht zu senden

Voraussetzungen

LTTH Dashboard und ein lokales Testprofil. Dieser konkrete Global Chat Command Engine-Ablauf behandelt Befehl, Berechtigung und Chat-Antwort.

Sicherheitsgrenzen

Verwende ausschließlich Demo-Ereignisse und ein temporäres Testprofil. Dieser konkrete Global Chat Command Engine-Ablauf behandelt Befehl, Berechtigung und Chat-Antwort.

Zweck und Zielgruppe

Global Chat Command Engine richtet Befehl, Berechtigung und Chat-Antwort ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Streamer:innen, die Befehl, Berechtigung und Chat-Antwort zuerst ohne LIVE-Auswirkung einrichten möchten.

Aktivierung und Navigation

Öffne im Plugin Manager „Global Chat Command Engine“, aktiviere es bei Bedarf und rufe dann die lokale Konfiguration auf.

/plugins/gcce/ui.html
