Global Chat Command Engine

Global Chat Command Engine richtet Befehl, Berechtigung und Chat-Antwort ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Voraussetzungen

LTTH Dashboard und ein lokales Testprofil.

Sicherheitsgrenzen

Verwende ausschließlich Demo-Ereignisse und ein temporäres Testprofil.

Schritt für Schritt

  1. 1

    Command Card im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Command Card von Befehl, Berechtigung und Chat-Antwort. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Die passende Plugin-Oberfläche ist eindeutig sichtbar.

  2. 2

    Command Name im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Command Name von Befehl, Berechtigung und Chat-Antwort. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  3. 3

    Permission Rule im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Permission Rule von Befehl, Berechtigung und Chat-Antwort. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  4. 4

    Command DRY RUN lokal testen

    Fuehre Command DRY RUN nur mit einen lokalen Testbefehl im isolierten Testprofil aus; keine LIVE-Quelle, Hardware oder externe Verbindung wird benutzt.

    Daran erkennst du den Erfolg: der Befehl wird validiert, ohne eine LIVE-Chatnachricht zu senden

  5. 5

    Command Review im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Command Review von Befehl, Berechtigung und Chat-Antwort. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Die Testkonfiguration ist nachvollziehbar und sicher gespeichert.

Fehlerbehebung

Wenn Befehl, Berechtigung und Chat-Antwort nicht sichtbar ist, prüfe zuerst den aktiven Plugin-Status, die lokale Route und gespeicherte Testwerte.
