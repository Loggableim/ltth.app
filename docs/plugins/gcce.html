Global Chat Command Engine

Global Chat Command Engine richtet Befehl, Berechtigung und Chat-Antwort ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Status
Entwicklungs-Beta
Version
1.0.0

Dein erstes Ergebnis

der Befehl wird validiert, ohne eine LIVE-Chatnachricht zu senden

Inhalt

  1. 1. Command Card im Testprofil konfigurieren
  2. 2. Command Name im Testprofil konfigurieren
  3. 3. Permission Rule im Testprofil konfigurieren
  4. 4. Command DRY RUN lokal testen
  5. 5. Command Review im Testprofil konfigurieren

Voraussetzungen

LTTH Dashboard und ein lokales Testprofil.

Sicherheitsgrenzen

Verwende ausschließlich Demo-Ereignisse und ein temporäres Testprofil.

Zweck und Zielgruppe

Global Chat Command Engine richtet Befehl, Berechtigung und Chat-Antwort ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Streamer:innen, die das Plugin zuerst ohne LIVE-Auswirkung einrichten möchten.

Aktivierung und Navigation

Öffne im Plugin Manager „Global Chat Command Engine“, aktiviere es bei Bedarf und rufe dann die lokale Konfiguration auf.

/plugins/gcce/ui.html

Verifizierte Workflows

Global Chat Command Engine im Testprofil einrichten

Öffne Befehl, Berechtigung und Chat-Antwort, setze ausschließlich die sichtbaren Testwerte, speichere sie und prüfe das lokale Ergebnis.

  1. command-card
  2. command-name
  3. permission-rule
  4. command-dry-run
  5. command-review

einen lokalen Testbefehl prüfen

Der Test bleibt lokal; er verbindet weder ein Konto noch eine LIVE-Ausgabe.

  1. command-dry-run
  2. command-review
