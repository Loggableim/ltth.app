Text-to-Speech System

Text-to-Speech System richtet Stimme, Warteschlange und Moderationsfilter ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Status
Funktionsfähige Beta
Version
2.0.1

Dein erstes Ergebnis

die Vorschau validiert Text und Stimme, ohne Audio auszugeben

Inhalt

  1. 1. TTS Card im Testprofil konfigurieren
  2. 2. Voice Select im Testprofil konfigurieren
  3. 3. Moderation Filter im Testprofil konfigurieren
  4. 4. Muted Voice Preview lokal testen
  5. 5. TTS Review im Testprofil konfigurieren

Voraussetzungen

LTTH Dashboard und ein lokales Audio-Ausgabegerät.

Sicherheitsgrenzen

Keine echten API-Schlüssel oder Konten eingeben; Platzhalter bleiben Platzhalter.

Zweck und Zielgruppe

Text-to-Speech System richtet Stimme, Warteschlange und Moderationsfilter ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Streamer:innen, die das Plugin zuerst ohne LIVE-Auswirkung einrichten möchten.

Aktivierung und Navigation

Öffne im Plugin Manager „Text-to-Speech System“, aktiviere es bei Bedarf und rufe dann die lokale Konfiguration auf.

/plugins/tts/ui/admin-panel.html

Fehlerbehebung

Die lokale Oberfläche oder Vorschau ist leer.

Pruefschritte Wenn Stimme, Warteschlange und Moderationsfilter nicht sichtbar ist, prüfe zuerst den aktiven Plugin-Status, die lokale Route und gespeicherte Testwerte. LTTH Dashboard und ein lokales Audio-Ausgabegerät.

Loesung Plugin-Status prüfen, die exakte lokale Route erneut öffnen und den Testwert im frischen Testprofil speichern.

Schritt für Schritt

  1. 1

    TTS Card im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich TTS Card von Stimme, Warteschlange und Moderationsfilter. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Die passende Plugin-Oberfläche ist eindeutig sichtbar.

  2. 2

    Voice Select im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Voice Select von Stimme, Warteschlange und Moderationsfilter. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  3. 3

    Moderation Filter im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Moderation Filter von Stimme, Warteschlange und Moderationsfilter. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  4. 4

    Muted Voice Preview lokal testen

    Fuehre Muted Voice Preview nur mit eine stumme lokale Sprachvorschau im isolierten Testprofil aus; keine LIVE-Quelle, Hardware oder externe Verbindung wird benutzt.

    Daran erkennst du den Erfolg: die Vorschau validiert Text und Stimme, ohne Audio auszugeben

  5. 5
