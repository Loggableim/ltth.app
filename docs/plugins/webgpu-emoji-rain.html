WebGPU EmojiRain

WebGPU EmojiRain richtet WebGPU-Preset, Assets und Geschenkregel ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Status
Entwicklungs-Beta
Version
3.0.2

Dein erstes Ergebnis

die GPU-Vorschau zeigt Emojis und meldet keinen LIVE-Kontakt

Inhalt

  1. 1. GPU Rain Card im Testprofil konfigurieren
  2. 2. GPU Preset sicher zuruecksetzen
  3. 3. Asset Rule im Testprofil konfigurieren
  4. 4. GPU Rain Test lokal testen
  5. 5. GPU Rain Overlay als Overlay-Vorschau oeffnen

Voraussetzungen

LTTH Dashboard; für die Ausgabe zusätzlich eine OBS-Testszene.

Sicherheitsgrenzen

Nutze eine nicht gesendete OBS-Testszene; LIVE-Ausgaben bleiben deaktiviert.

Schritt für Schritt

  1. 1

    GPU Rain Card im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich GPU Rain Card von WebGPU-Preset, Assets und Geschenkregel. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Die passende Plugin-Oberfläche ist eindeutig sichtbar.

  2. 2

    GPU Preset sicher zuruecksetzen

    Entferne nur die Demo-Werte fuer GPU Preset, bevor du WebGPU-Preset, Assets und Geschenkregel produktiv vorbereitest.

    Daran erkennst du den Erfolg: Das Testprofil bleibt ohne produktive Auswirkung.

  3. 3

    Asset Rule im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Asset Rule von WebGPU-Preset, Assets und Geschenkregel. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  4. 4

    GPU Rain Test lokal testen

    Fuehre GPU Rain Test nur mit ein lokales Emoji-Regen-Testereignis im isolierten Testprofil aus; keine LIVE-Quelle, Hardware oder externe Verbindung wird benutzt.

    Daran erkennst du den Erfolg: die GPU-Vorschau zeigt Emojis und meldet keinen LIVE-Kontakt

  5. 5

    GPU Rain Overlay als Overlay-Vorschau oeffnen

    Oeffne die echte GPU Rain Overlay-Oberflaeche ausschliesslich in einer nicht sendenden OBS-Testszene.

    Daran erkennst du den Erfolg: die GPU-Vorschau zeigt Emojis und meldet keinen LIVE-Kontakt

  6. 6

    GPU Rain Reset sicher zuruecksetzen

    Entferne nur die Demo-Werte fuer GPU Rain Reset, bevor du WebGPU-Preset, Assets und Geschenkregel produktiv vorbereitest.

    Daran erkennst du den Erfolg: Das Testprofil bleibt ohne produktive Auswirkung.

Overlay und OBS

Füge diese URL erst in eine nicht gesendete OBS-Testszene als Browser-Quelle ein.

/plugins/webgpu-emoji-rain/overlay.html

Fehlerbehebung

Wenn WebGPU-Preset, Assets und Geschenkregel nicht sichtbar ist, prüfe zuerst den aktiven Plugin-Status, die lokale Route und gespeicherte Testwerte.
