Minecraft Connect

Pruefe die lokale Bridge-Oberflaeche, ohne einen Minecraft-Server anzusprechen.

Status
Frühe Version
Version
1.0.0

Dein erstes Ergebnis

Die Offline- und Setupfelder sind sichtbar.

Inhalt

  1. 1. Befehlsansicht pruefen
  2. 2. Loopback-Host pruefen
  3. 3. Chat-Ziele nur ansehen
  4. 4. Test Action nicht ausloesen
  5. 5. Offline-Status lesen

Voraussetzungen

Aktives Plugin und lokales Testprofil.

Sicherheitsgrenzen

Host bleibt localhost; Test Action nicht ausloesen.

Schritt für Schritt

  1. 1

    Befehlsansicht pruefen

    Lies die Befehlsansicht nur lokal.

    Daran erkennst du den Erfolg: Die Befehlsansicht ist sichtbar.

  2. 2

    Loopback-Host pruefen

    Kontrolliere, dass der sichtbare Host localhost bleibt.

    Daran erkennst du den Erfolg: Das Hostfeld ist sichtbar.

  3. 3

    Chat-Ziele nur ansehen

    Pruefe das Ziel-Feld ohne ein externes Ziel zu speichern.

    Daran erkennst du den Erfolg: Das Ziel-Feld ist sichtbar.

  4. 4

    Test Action nicht ausloesen

    Identifiziere die Test-Schaltflaeche, ohne sie zu betaetigen.

    Daran erkennst du den Erfolg: Die Test-Schaltflaeche ist sichtbar und unbetaetigt.

  5. 5

    Offline-Status lesen

    Pruefe den Verbindungsstatus ohne eine Bridge zu starten.

    Daran erkennst du den Erfolg: Der Verbindungsstatus ist sichtbar.

Fehlerbehebung

Bei fehlender Ansicht /minecraft-connect/ui neu laden.
