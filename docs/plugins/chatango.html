Chatango Integration

Chatango Integration richtet Raumname, Widget-Position und Chat-Thema ein – mit einer sicheren lokalen Kontrolle statt einer LIVE-Auslösung.

Status
Frühe Version
Version
1.0.0

Dein erstes Ergebnis

das Widget zeigt die gewählte Position ohne einen externen Chat zu öffnen

Inhalt

  1. 1. Chatango Card im Testprofil konfigurieren
  2. 2. Room Placeholder im Testprofil konfigurieren
  3. 3. Widget Position im Testprofil konfigurieren
  4. 4. Widget Preview lokal testen
  5. 5. Chatango Review lokal testen

Voraussetzungen

LTTH Dashboard; externe Endpunkte bleiben in dieser Anleitung getrennt.

Sicherheitsgrenzen

Keine echten API-Schlüssel oder Konten eingeben; Platzhalter bleiben Platzhalter.

Schritt für Schritt

  1. 1

    Chatango Card im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Chatango Card von Raumname, Widget-Position und Chat-Thema. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Die passende Plugin-Oberfläche ist eindeutig sichtbar.

  2. 2

    Room Placeholder im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Room Placeholder von Raumname, Widget-Position und Chat-Thema. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  3. 3

    Widget Position im Testprofil konfigurieren

    Arbeite im sichtbaren Bereich Widget Position von Raumname, Widget-Position und Chat-Thema. Verwende nur lokale Demo-Werte; keine Zugangsdaten, Geraete-ID oder LIVE-Ziel.

    Daran erkennst du den Erfolg: Der Demo-Wert ist sichtbar und kann vor dem Test geprüft werden.

  4. 4

    Widget Preview lokal testen

    Fuehre Widget Preview nur mit die lokale Widget-Vorschau mit einem Platzhalterraum im isolierten Testprofil aus; keine LIVE-Quelle, Hardware oder externe Verbindung wird benutzt.

    Daran erkennst du den Erfolg: das Widget zeigt die gewählte Position ohne einen externen Chat zu öffnen

  5. 5

    Chatango Review lokal testen

    Fuehre Chatango Review nur mit die lokale Widget-Vorschau mit einem Platzhalterraum im isolierten Testprofil aus; keine LIVE-Quelle, Hardware oder externe Verbindung wird benutzt.

    Daran erkennst du den Erfolg: das Widget zeigt die gewählte Position ohne einen externen Chat zu öffnen

Overlay und OBS

Füge diese URL erst in eine nicht gesendete OBS-Testszene als Browser-Quelle ein.

/plugins/chatango/ui.html

Fehlerbehebung

Wenn Raumname, Widget-Position und Chat-Thema nicht sichtbar ist, prüfe zuerst den aktiven Plugin-Status, die lokale Route und gespeicherte Testwerte.
