Encuentra respuestas a las preguntas más comunes sobre ltth.app

🚀 Primeros pasos

☁️ ¿Qué es el Cloud Launcher?

El Cloud Launcher es una pequeña aplicación de Windows (~7 MB) que descarga, instala y mantiene automáticamente LTTH actualizado. Ofrece actualizaciones automáticas, rollback y gestión integrada de versiones.

🛡️ ¿Por qué SmartScreen muestra una advertencia?

El launcher es una nueva aplicación que aún no ha sido firmada. Haga clic en 'Más información' → 'Ejecutar de todos modos'.

🍎 ¿Está LTTH disponible para macOS o Linux?

El Cloud Launcher solo está disponible actualmente para Windows. El soporte para macOS y Linux está planeado.

💰 ¿Es PupCid's Little TikTool Helper gratuito?

¡Sí, completamente gratis! La herramienta es 100% gratuita y Open Source (Licencia MIT). No hay costes ocultos, niveles premium ni restricciones de funciones. Todas las funciones están disponibles gratuitamente para todos.

💻 ¿Qué sistemas operativos son compatibles?

Launcher: Solo Windows 10/11
LTTH en sí: Windows, macOS y Linux

Windows: Windows 10/11 (64-bit) con Cloud Launcher - instalación más sencilla
macOS: macOS 10.15+ - instalación manual vía npm
Linux: Ubuntu 20.04+, Debian 11+ - instalación manual vía npm

Todas las plataformas requieren Node.js 18.0.0 o superior. Consulta la Guía de instalación para más detalles.

🔑 ¿Necesito introducir credenciales de inicio de sesión?

¡No, no se requieren credenciales! Solo necesitas tu nombre de usuario de TikTok (sin @). Sin contraseñas, sin OAuth, sin conexión de cuenta. La herramienta solo lee datos de stream LIVE públicamente disponibles.

🚀 ¿Qué significa "Versión Beta"? ¿Es estable?

¡Sí, la herramienta está lista para producción y es completamente funcional! "Beta" significa que se están desarrollando activamente nuevas funciones y estamos recopilando feedback. Todas las funciones principales (TTS, Alertas, Soundboard, Plugins, integración OBS) funcionan de manera fiable. Pueden ocurrir bugs ocasionales - simplemente repórtalos en GitHub y los solucionaremos rápidamente.

🔒 ¿Se suben mis datos a la nube?

¡No, todo permanece local! Todos los datos permanecen en tu ordenador. Sin conexión a la nube, sin recopilación de datos, sin tracking. 100% local y privado.

🔧 Solución de problemas

❌ La conexión con TikTok falla - ¿qué hacer?

Soluciones comunes:
✅ Debes estar ya en LIVE en TikTok (no en vista previa)
✅ El nombre de usuario debe ser correcto (sin @)
✅ El firewall/antivirus podría estar bloqueando la conexión
✅ El puerto 3000 debe estar disponible
✅ Prueba la reconexión automática (se intenta automáticamente)

Más ayuda: Guía de solución de problemas

🔊 TTS no funciona - ¿no hay sonido?

Lista de verificación:
✅ ¿Plugin TTS activado? (Dashboard → Plugins)
✅ ¿Volumen del sistema no está en silencio?
✅ ¿Dispositivo de audio predeterminado configurado correctamente?
✅ ¿Volumen TTS subido en el Dashboard?
✅ Prueba el botón de Test en el panel de administración TTS

Si nada ayuda: Contactar soporte

🤖 IA y datos

🤖 ¿Qué es AnimazingPal?

AnimazingPal es un plugin impulsado por IA que da memoria y personalidad a los avatares VTuber. Recuerda a los espectadores, genera respuestas contextuales a través de GPT y agrupa eventos para un flujo de habla natural.

🔑 ¿Necesito una clave API de OpenAI?

Sí, se necesita una clave API de OpenAI para el Brain Engine y Response Engine de AnimazingPal. Se admiten GPT-4o-mini y GPT-5 Nano. La clave se almacena de forma segura y persistente.

💾 ¿Se sobrescribirán mis datos durante las actualizaciones?

No. Todos los datos de usuario, configuraciones y claves API se almacenan en las carpetas user_data/ y user_configs/ y sobreviven a las actualizaciones.
