Guía de instalación (Launcher Windows)

1

Descargar el Launcher

Haz clic en el botón "Descargar Launcher" arriba para descargar launcher.exe (~6.6 MB).

2

Ejecutar el Launcher

Haz doble clic en el archivo launcher.exe descargado. El launcher te guiará a través de la instalación y descargará automáticamente la última versión de LTTH.

3

Elegir la ruta de instalación

En el primer inicio, puedes seleccionar dónde debe instalarse LTTH. Las rutas predeterminadas están preconfiguradas, pero puedes personalizarlas según tus necesidades.

4

Conectar con TikTok

Después de la instalación, LTTH se inicia automáticamente. El panel de control se abre en tu navegador. ¡Introduce tu nombre de usuario de TikTok (sin @) y conéctate a tu stream LIVE!

Instalación manual (Avanzado)

Alternativamente, puedes descargar el archivo ZIP para macOS, Linux o si prefieres la instalación manual:

  1. Descarga ltth_latest.zip
  2. Extrae el archivo ZIP
  3. Ejecuta start.exe (Windows), start-linux (Linux) o start-mac (macOS)
  4. Node.js 18.0.0+ debe estar ya instalado

Requisitos del sistema

Launcher Windows:

  • Windows 10/11 (64-bit)
  • WebView2 Runtime (preinstalado en Windows 10/11)
  • Conexión a internet activa para actualizaciones y TikTok LIVE
  • Al menos 512 MB de RAM (1 GB recomendado)
  • ~50 MB de espacio libre en disco

Instalación manual (ZIP):

  • Node.js 18.0.0 o superior (Descargar: nodejs.org)
  • Windows 10+ (64-bit), macOS 10.15+, o Linux (Ubuntu 20.04+, Debian 11+)
  • Conexión a internet activa para TikTok LIVE
  • Al menos 512 MB de RAM (1 GB recomendado)
  • 200 MB de espacio libre en disco

Recomendado para todas las instalaciones: OBS Studio para overlays Browser Source

🔄 Actualizaciones automáticas

El launcher verifica automáticamente las actualizaciones al inicio y descarga la última versión de LTTH. Tu configuración y ajustes se conservan durante las actualizaciones.
