Télécharger ltth.app

Téléchargez la solution de streaming TikTok LIVE professionnelle pour Windows, macOS et Linux. Gratuit, rapide et sécurisé.

Toutes les plateformes

Windows, macOS, Linux

Télécharger ZIP

Extraire et exécuter start.exe (Windows) ou start.sh (Linux/macOS)

Guide d'installation

1

Télécharger le fichier ZIP

Cliquez sur le bouton de téléchargement ci-dessus pour obtenir la dernière version de PupCid's Little TikTool Helper.

2

Extraire et démarrer

Windows : Double-cliquez sur start.exe
Linux : Double-cliquez sur start-linux ou dans le terminal : ./start-linux
macOS : Double-cliquez sur start-mac ou dans le terminal : ./start-mac
L'outil installe automatiquement toutes les dépendances requises et se lance.

3

Connectez-vous à TikTok

Le tableau de bord s'ouvre automatiquement dans votre navigateur. Entrez votre nom d'utilisateur TikTok (sans @) et connectez-vous à votre stream LIVE. Assurez-vous d'être en LIVE !

Configuration requise

Toutes les plateformes :

  • Node.js 18.0.0 ou supérieur (Télécharger : nodejs.org)
  • Windows 10+ (64-bit), macOS 10.15+, ou Linux (Ubuntu 20.04+, Debian 11+)
  • Connexion internet active pour TikTok LIVE
  • Au moins 512 Mo de RAM (1 Go recommandé)
  • 200 Mo d'espace disque libre
  • OBS Studio (recommandé pour les overlays)

⚠️ Important : Si Node.js n'est pas installé, un message d'erreur avec un lien de téléchargement apparaîtra.
