LTTH Cloud Launcher

Version 1.3.2

Installation en un clic avec mises à jour automatiques, rollback et gestion des versions. Téléchargez, lancez et c'est parti.

Télécharger le Launcher

~7 Mo · Windows 10+

Guide d'installation

1

Télécharger

Téléchargez le LTTH Cloud Launcher (~7 Mo).

2

Exécuter

Double-cliquez sur launcher.exe.

Remarque : Windows SmartScreen peut afficher un avertissement. Cliquez « Informations complémentaires » → « Exécuter quand même ».

3

Configuration initiale

Choisissez le chemin d'installation → Cliquez « Suivant »

4

Installation automatique

Le launcher télécharge et installe automatiquement la dernière version

5

Terminé !

Cliquez « Démarrer » pour lancer LTTH

Fonctionnalités

  • ✅ Installation automatique – Pas d'extraction manuelle, pas de terminal
  • ✅ Mises à jour automatiques – Vérification à chaque démarrage
  • ✅ Rollback – Paramètres → Versions → sélectionner une version précédente
  • ✅ Gestion des versions intégrée
  • ✅ Séparation propre – Les données survivent aux mises à jour
  • ✅ Seulement ~7 Mo – Télécharge l'application complète automatiquement

Configuration requise

  • Système d'exploitation : Windows 10 ou plus récent
  • Espace disque : ~500 Mo d'espace disque libre
  • RAM : 512 Mo minimum, 1 Go recommandé
  • Internet : Connexion Internet requise
  • WebView2 Runtime : Inclus avec Windows 10/11. Si absent : Télécharger WebView2

Dépannage

Avertissement SmartScreen :

Le launcher est une nouvelle application qui n'a pas encore été signée. Cliquez « Informations complémentaires » → « Exécuter quand même ».

Fenêtre blanche :

Installez WebView2 Runtime. Télécharger

Échec de mise à jour :

  • Vérifiez la connexion Internet
  • Vérifiez le pare-feu
  • Vérifiez les logs

🔄 Mises à jour automatiques

Le launcher vérifie automatiquement les mises à jour au démarrage et télécharge la dernière version de LTTH. Votre configuration et vos paramètres sont préservés lors des mises à jour.
