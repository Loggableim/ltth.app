Guide d'installation (Launcher Windows)

1

Télécharger le Launcher

Cliquez sur le bouton "Télécharger le Launcher" ci-dessus pour télécharger launcher.exe (~6.6 MB).

2

Exécuter le Launcher

Double-cliquez sur le fichier launcher.exe téléchargé. Le launcher vous guidera à travers l'installation et téléchargera automatiquement la dernière version de LTTH.

3

Choisir le chemin d'installation

Au premier lancement, vous pouvez sélectionner où LTTH doit être installé. Les chemins par défaut sont préconfigurés, mais vous pouvez les personnaliser selon vos besoins.

4

Se connecter à TikTok

Après l'installation, LTTH démarre automatiquement. Le tableau de bord s'ouvre dans votre navigateur. Entrez votre nom d'utilisateur TikTok (sans @) et connectez-vous à votre stream LIVE !

Installation manuelle (Avancé)

Alternativement, vous pouvez télécharger le fichier ZIP pour macOS, Linux ou si vous préférez l'installation manuelle :

  1. Téléchargez ltth_latest.zip
  2. Extrayez l'archive ZIP
  3. Exécutez start.exe (Windows), start-linux (Linux) ou start-mac (macOS)
  4. Node.js 18.0.0+ doit être déjà installé

Configuration requise

Launcher Windows :

  • Windows 10/11 (64-bit)
  • WebView2 Runtime (préinstallé sur Windows 10/11)
  • Connexion internet active pour les mises à jour & TikTok LIVE
  • Au moins 512 Mo de RAM (1 Go recommandé)
  • ~50 Mo d'espace disque libre

Installation manuelle (ZIP) :

  • Node.js 18.0.0 ou supérieur (Télécharger : nodejs.org)
  • Windows 10+ (64-bit), macOS 10.15+, ou Linux (Ubuntu 20.04+, Debian 11+)
  • Connexion internet active pour TikTok LIVE
  • Au moins 512 Mo de RAM (1 Go recommandé)
  • 200 Mo d'espace disque libre

Recommandé pour toutes les installations : OBS Studio pour les overlays Browser Source

🔄 Mises à jour automatiques

Le launcher vérifie automatiquement les mises à jour au démarrage et télécharge la dernière version de LTTH. Votre configuration et vos paramètres sont préservés lors des mises à jour.
