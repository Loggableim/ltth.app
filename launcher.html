Was ist der Launcher?

Der LTTH Standalone Launcher ist eine eigenständige Windows-Anwendung (.exe), die den gesamten Installations- und Update-Prozess von PupCid's Little TikTool Helper übernimmt.

Kein manuelles Installieren von Node.js, kein Terminal, keine Konfigurationsdateien. Einfach Launcher starten – der Rest passiert automatisch.

  • ✓ Keine Vorkenntnisse erforderlich
  • ✓ Vollständige Voraussetzungs-Prüfung
  • ✓ Automatische Updates ohne Neuinstallation
  • ✓ Mehrere Profile für verschiedene TikTok-Accounts

Launcher-Steuerung und Diagnose

Tab 1

Status

Live-Status von App, Server und allen Diensten. Start/Stop-Controls, Log-Ausgabe in Echtzeit und Verbindungs-Diagnose auf einen Blick.

Tab 2

API & Systems

API-Keys konfigurieren (Azure, ElevenLabs), System-Checks ausführen und Abhängigkeiten verwalten – alles an einem Ort.

Tab 3

Features

Alle LTTH-Features aktivieren und deaktivieren: TTS, Overlays, Soundboard, Plugins – schneller Toggle ohne das Admin-UI zu öffnen.

Tab 4

Profiles

Mehrere Konfigurationsprofile für verschiedene TikTok-Accounts oder Stream-Szenarien. Profil-Wechsel in Sekunden, mit separaten Einstellungen pro Profil.

Tab 5

Settings

Launcher-Einstellungen: Autostart mit Windows, Update-Kanal (Stable/Beta), Port-Konfiguration, Sprache und UI-Optionen.
