Config Import – Backup & Restore

Exportiere, importiere und migriere deine komplette Plugin‑Konfiguration in wenigen Klicks. Version 2.0.0 – working‑beta.

Jetzt Herunterladen Dokumentation

Funktionen im Detail

📦

ZIP Export

Exportiere sämtliche Plugin‑Einstellungen in ein komprimiertes ZIP‑Archiv. Inklusive aller Datenbanken und Konfigurationsdateien.

Export ZIP
📦

ZIP Import

Importiere ein zuvor exportiertes ZIP‑Archiv und überschreibe die aktuelle Konfiguration. Unterstützt sowohl neue als auch legacy‑Formate.

Import ZIP
🔍

Konflikt‑Vorschau

Vor dem Import werden potenzielle Konflikte zwischen bestehender und neuer Konfiguration angezeigt. Du kannst entscheiden, welche Werte übernommen werden.

Vorschau Konflikte
🔄

Legacy Migration

Migriere Konfigurationen aus älteren Installationspfaden (z. B. vor Version 1.0) automatisch in das neue Format. Kompatibel mit allen bisherigen Versionen.

Migration Legacy
