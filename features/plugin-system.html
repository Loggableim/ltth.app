Kern-Features

🧩

30+ Eingebaute Plugins

Sofort einsatzbereite Plugins für alle wichtigen Streaming-Funktionen: TTS, Soundboard, Overlays, Alerts, Goals, Leaderboards und viele mehr.

🔄

Hot-Reload

Plugins aktivieren, deaktivieren und aktualisieren ohne den Server neu zu starten. Änderungen am Plugin-Code werden sofort übernommen.

🛠️

JavaScript API

Vollständige Plugin-API in JavaScript. Eigene Plugins mit Zugriff auf alle Events, TTS, Overlays, Soundboard und Admin-UI schreiben.

🪝

Event Hooks & Trigger

Eigene Hooks auf alle TikTok-Events registrieren: Chat, Gifts, Follows, Subscriptions, Room State und mehr. Vollständige Event-Daten im Plugin verfügbar.

🛡️

Admin-UI Integration

Eigene Einstellungsseiten im Admin-Panel registrieren. Plugins können eigene UI-Komponenten, Settings-Forms und Dashboard-Widgets hinzufügen.

🎙️

Sandboxed Execution

Plugins laufen in einer isolierten Umgebung. Fehlgeschlagene Plugins crashen nicht den Server. Automatische Fehlerbehandlung und Plugin-Logging.

Plugin entwickeln

Ein Plugin besteht aus einer einzigen JavaScript-Datei. Mit wenigen Zeilen Code kannst du auf alle TikTok-Events reagieren und den Stream automatisieren.

// Beispiel: Eigenes Plugin
module.exports = {
name: 'my-plugin',
version: '1.0.0',
onGift(event, api) {
api.tts(`${event.user} hat ein Geschenk gesendet!`);
api.playSound('fanfare');
}
};
