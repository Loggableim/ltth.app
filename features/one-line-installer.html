One-Line Installer NEU in v1.3.7

Ein einziger Befehl — und LTTH läuft. Funktioniert auf Windows, macOS und Linux. Auto-Detect für Git und Node.js, automatisches Setup, fertig.

Zur Download-Seite GitHub

Drei Befehle, drei Plattformen

🪟 Windows (PowerShell)

PS> iwr -useb https://ltth.app/install.ps1 | iex

🍎 macOS (Terminal)

$ curl -fsSL https://ltth.app/install.sh | bash

🐧 Linux (Bash)

$ curl -fsSL https://ltth.app/install.sh | bash

🌐 Universal (Node.js)

$ curl -fsSL https://ltth.app/install.js | node

Was die Installer tun

1. 🩺 Prüfen

Git und Node.js (>= 18, < 25) werden erkannt. Fehlende Tools werden via Homebrew, winget, NodeSource oder apt automatisch installiert.

2. 📥 Laden

Das LTTH-Repository wird von GitHub geklont (oder aktualisiert, falls schon installiert). Standard-Pfad: ~/.local/share/ltth bzw. %LOCALAPPDATA%\LTTH.

3. 🔨 Bauen

npm install richtet alle 38+ Plugins und Module ein. Keine manuellen Schritte nötig.

4. 🚀 Starten

Die App wird im Hintergrund gestartet. Das Dashboard öffnet sich automatisch unter http://localhost:3000/dashboard.html.

5. 🔄 Updates

git pull && npm install reicht — keine separaten Update-Tools, keine EXE-Downloads.

6. 🧹 Deinstallation

Einfach das Installations-Verzeichnis löschen. Keine Registry-Einträge, keine Systemdateien.

Umgebungsvariablen

Variable Default Bedeutung
LTTH_VERSIONlatestVersion (z.B. v1.3.7)
LTTH_DIR~/.local/share/ltthInstallationspfad
LTTH_PORT3000HTTP-Port
LTTH_NO_BROWSER0Browser nicht öffnen (1 = aus)
LTTH_QUIET0Reduzierte Ausgabe (1 = still)

Beispiel: LTTH_PORT=8080 LTTH_VERSION=v1.3.5 curl -fsSL https://ltth.app/install.sh | bash

Probier's aus

Dreißig Sekunden, ein Befehl — und du hast die komplette LTTH-Suite laufen.
