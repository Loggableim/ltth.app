Was ist neu in v2.0?

🔄 Session-only-Modus

Das Leaderboard startet bei jedem Stream automatisch bei null. Keine Datenleichen aus alten Streams mehr, jede Session ist ein neuer Wettkampf.

🪙 Coins = Score

Vereinheitlichte Punkte-Logik: 1 Coin = 1 Punkt. Keine Konvertierung, keine Verwirrung — was im Chat passiert, ist das Ranking.

📊 Kombinierte Live-View

Top-Gifter + Top-Chatter + Top-Follower in einer einzigen Ansicht. Multi-Modal-Engagement auf einen Blick.

📱📺 Portrait & Landscape

Optimierte Layouts für Mobile-Viewing (TikTok selbst) und Desktop-Streaming (OBS Browser Source).

✨ Glassmorphism Overlay v3.0

Neues Design mit Backdrop-Blur, halbtransparenten Flächen und subtilen Akzenten. Sieht auf jedem Stream-Hintergrund elegant aus.

🎨 Theme-Aware

Automatische Anpassung an Light- und Dark-Themes. Konfigurierbare Akzentfarbe.

Konfiguration

TopTier findest du im Dashboard unter Plugins → TopTier. Konfigurierbar:

  • Session-Reset-Verhalten (auto / manuell)
  • Welche Event-Quellen zählen (Gifts, Subs, Likes, Follows)
  • Anzeige-Layout (Portrait / Landscape / Combined)
  • Overlay-Position und Akzentfarbe
  • TTS-Trigger bei Leaderboard-Wechsel

Das Overlay wird als separate OBS-Browser-Source eingebunden — typische URL: http://localhost:3000/overlay/toptier.
