OSC / VRChat Bridge

Verbinde dein TikTok LIVE direkt mit VRChat. Lass deine Zuschauer deinen Avatar steuern, Animationen triggern und – mit OpenShock – sogar physisches Feedback senden.

VRChat OSC Integration

📡

VRChat OSC

Vollständige VRChat OSC-Integration über das offizielle OSC-Protokoll. Verbindet sich automatisch mit VRChat auf localhost:9000 und sendet/empfängt Parameter in Echtzeit.

🎭

Avatar Parameter Control

Beliebige Avatar-Parameter per TikTok-Event steuern: Bool, Int und Float-Parameter aus deinen Custom-Animationen sind vollständig mappbar.

💬

Chat → Expression

Chat-Keywords und Commands triggern Avatar-Expressionen direkt. Konfiguriere z.B. dass "!wave" eine Winke-Animation auslöst oder "!dance" eine Tanz-Loop startet.

🎁

Gift → Animation

Jedes TikTok Gift kann einer Avatar-Animation zugeordnet werden. Wertvolle Gifts triggern spektakuläre Animationen, einfache Gifts reagieren subtiler.

🗺️

Parameter Mapper

Visueller Parameter-Mapper im Admin-UI. Drag-and-Drop TikTok-Events auf OSC-Parameter. Automatische Typ-Konvertierung und Wertebereich-Konfiguration.

⚡ NEU

OpenShock / PiShock

Integration mit OpenShock und PiShock für haptisches Feedback. Gifts und Events können Vibrationen oder Impulse auslösen – für das ultimative interaktive Stream-Erlebnis.

Verbindungs-Setup

1

VRChat starten

OSC in VRChat aktivieren: Settings → OSC → Enable

2

LTTH verbinden

Im Admin-UI OSC Bridge aktivieren und Port 9000 konfigurieren

3

Parameter mappen

TikTok-Events auf deine Avatar-Parameter im visuellen Mapper zuordnen

4

Streamen!

Dein Avatar reagiert live auf Chat, Gifts und Events deiner Zuschauer

VRChat Bridge aktivieren

Dein Avatar und dein TikTok Chat werden eins – lade LTTH kostenlos herunter.
