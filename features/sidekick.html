Sidekick Features im Detail

🦾

AnimazingPal Delegation

Automatisches Auslösen von Avatar- und Sprachaktionen über die AnimazingPal API – nahtlose Integration in deinen Stream.

🐟

Fish.audio Integration

KI-Stimmen mit Voice‑Cloning aus der Fish.audio API – sofort einsatzbereit für Live‑Antworten.

🔍

Event‑Analyse

Echtzeit‑Analyse von TikTok‑Events, Giften, Spenden und Interaktionen, um sofortige Reaktionen zu ermöglichen.

🧠

Benutzer‑Gedächtnis mit Verfall

Speichert Interaktionshistorie pro Viewer, verfallen nach definiertem Zeitraum, um Kontext zu behalten.

📦

Nachrichten‑Batching

Gruppiert mehrere Ereignisse zu einer einzigen Antwort, um Flut‑Spam zu reduzieren.

⚖️

Relevanz‑Scoring

Bewertet die Wichtigkeit von Events, um Prioritäten für automatische Antworten zu bestimmen.

📊

Stream‑Analytik

Umfassende Dashboards für Interaktionsstatistiken, Reaktionszeiten und Zuschauer‑Engagement.
