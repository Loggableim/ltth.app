Installation Guide (Windows Launcher)

1

Download Launcher

Click the "Download Launcher" button above to download launcher.exe (~6.6 MB).

2

Run Launcher

Double-click the downloaded launcher.exe file. The launcher will guide you through the installation and automatically download the latest version of LTTH.

3

Choose Installation Path

On first launch, you can select where LTTH should be installed. Default paths are preconfigured, but you can customize them as needed.

4

Connect to TikTok

After installation, LTTH starts automatically. The dashboard opens in your browser. Enter your TikTok username (without @) and connect to your LIVE stream!

Manual Installation (Advanced)

Alternatively, you can download the ZIP file for macOS, Linux, or if you prefer manual installation:

  1. Download ltth_latest.zip
  2. Extract the ZIP archive
  3. Run start.exe (Windows), start-linux (Linux) or start-mac (macOS)
  4. Node.js 18.0.0+ must be already installed

System Requirements

Windows Launcher:

  • Windows 10/11 (64-bit)
  • WebView2 Runtime (pre-installed on Windows 10/11)
  • Active internet connection for updates & TikTok LIVE
  • At least 512 MB RAM (1 GB recommended)
  • ~50 MB free disk space

Manual Installation (ZIP):

  • Node.js 18.0.0 or higher (Download: nodejs.org)
  • Windows 10+ (64-bit), macOS 10.15+, or Linux (Ubuntu 20.04+, Debian 11+)
  • Active internet connection for TikTok LIVE
  • At least 512 MB RAM (1 GB recommended)
  • 200 MB free disk space

Recommended for all installations: OBS Studio for Browser Source overlays

🔄 Automatic Updates

The launcher automatically checks for updates on startup and downloads the latest version of LTTH. Your configuration and settings are preserved during updates.
