Installation Guide

1

Download

Download the LTTH Cloud Launcher (~7 MB).

2

Run

Double-click launcher.exe to run.

Note: Windows SmartScreen may show a warning. Click "More info" → "Run anyway". The file is safe.

3

Initial Setup

Choose installation path → Click "Next"

4

Automatic Installation

The launcher automatically downloads and installs the latest version

5

Done!

Click "Start" to launch LTTH

Features

  • ✅ Automatic installation – No manual extraction, no terminal
  • ✅ Automatic updates – Checks on every launch, one click to update
  • ✅ Rollback – Settings → Versions → select previous version
  • ✅ Version management – All installed versions visible
  • ✅ Clean separation – App data in %LOCALAPPDATA%\LTTH\, config survives updates
  • ✅ Only ~7 MB – Launcher downloads the full app (~25 MB) automatically

System Requirements

  • Operating System: Windows 10 or newer
  • Disk Space: ~500 MB free disk space
  • RAM: 512 MB minimum, 1 GB recommended
  • Internet: Internet connection required
  • WebView2 Runtime: Included with Windows 10/11. If not present: Download WebView2

Troubleshooting

SmartScreen warning:

The launcher is a new application that hasn't been code-signed yet. Click "More info" → "Run anyway".

White window:

Install WebView2 Runtime. Download

Update fails:

  • Check internet connection
  • Check firewall/antivirus
  • Check logs: %LOCALAPPDATA%\LTTH\launcher.log

🔄 Automatic Updates

The launcher automatically checks for updates on startup and downloads the latest version of LTTH. Your configuration and settings are preserved during updates.
