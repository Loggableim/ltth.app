📋 OBS Browser Source Einrichtung

1. In OBS eine neue Browser Source erstellen

2. URL eingeben: http://localhost:3000/flame-overlay/overlay

3. Breite und Höhe entsprechend deiner Auswahl einstellen

4. "Shutdown source when not visible" deaktivieren (für bessere Performance)

5. Transparenter Hintergrund ist bereits aktiviert ✅

💡 Tipps

• Rahmen Position: Wähle "Unten" für klassisches TikTok-Layout, "Rundherum" für volle Immersion

• Intensität: Höhere Werte erzeugen wildere, chaotischere Flammen

• Geschwindigkeit: Niedrigere Werte für ruhige, höhere für energetische Flammen

• Additive Blending: Macht Flammen heller und leuchtender (empfohlen)
